EV Launch in China — Project Charter

1. Project Overview

This is a simulated project to plan the launch of an affordable electric vehicle in China.

2. Project Goal

The goal is to prepare a launch plan for an electric vehicle designed for young professionals and first-time car buyers.

3. Target Customers

* Young professionals
* First-time car buyers
* Customers looking for an affordable electric vehicle

4. Project Scope

The project will focus on:

* Understanding customer needs
* Studying competing electric vehicles
* Planning marketing activities
* Creating a project timeline
* Identifying project risks

This project does not include designing or manufacturing the actual vehicle.

5. Main Stakeholders

* Project Manager
* Product Manager
* Marketing Team
* Engineering Team
* Potential Customers

6. Success Criteria

* Complete a clear project plan
* Identify the main customer needs
* Prepare a realistic timeline
* Identify major risks and possible solutions

7. Project Status

Planning

8. Project Type

Educational case study — not a real company launch.
